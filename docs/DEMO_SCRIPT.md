# DSLT Demo Script

## 1) Member Journey
1. Register member
2. Login as member
3. Deposit savings
4. Withdraw savings
5. Apply for a loan
6. View “My Loans” to see schedule and totals

## 2) Admin Journey
1. Login as admin
2. Go to Approve Loans → approve pending request
3. Visit Members → search member → view → edit member
4. Go to Transactions → add + reverse transaction
5. View Reports
6. View Audit Logs for recorded admin actions

## 3) Repayment
1. Member makes repayment
2. System updates paid/balance automatically
3. When fully repaid, loan status changes to “closed”
